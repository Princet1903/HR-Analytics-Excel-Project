# 📊 HR Analytics Dashboard

## 🚀 Project Overview
Developed an interactive HR Analytics Dashboard in Microsoft Excel to analyze workforce data and uncover actionable business insights. The dashboard helps track employee attrition, workforce demographics, salary distribution, and key HR performance indicators, enabling data-driven decision-making.

---

## 🛠️ Tools & Techniques Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- XLOOKUP
- INDEX-MATCH
- Conditional Formatting
- Data Cleaning & Transformation
- Interactive Dashboard Design
- KPI Reporting

---

## 📈 Key KPIs Tracked
✔ Total Employees  
✔ Active Employees  
✔ Attrition Count  
✔ Attrition Rate (%)  
✔ Average Salary  
✔ Department-wise Employee Distribution  

---

## 🎯 Dashboard Features
- Interactive and user-friendly dashboard
- Dynamic KPI cards for quick performance tracking
- Department-wise workforce analysis
- Employee attrition analysis
- Salary trend and distribution analysis
- Filter-based insights using Excel functionalities

---

## 💡 Business Insights
- Identified departments with the highest employee concentration.
- Analyzed employee attrition trends to highlight retention challenges.
- Evaluated salary distribution across different workforce segments.
- Generated actionable insights to support HR planning and decision-making.
- Improved visibility of workforce metrics through interactive visualizations.
